# 动效选用与排期

分镜决定解释什么，风格决定画面语言，本文件提供可复用的动作配方。默认参数集中在 [motion-presets.json](../assets/motion-presets.json)，用于技术动态图解；其他风格可明确覆盖节奏和幅度。配方 ID 不是 Remotion 组件或全片开关，Agent 仍需实现帧驱动代码。

## 先确定动作的作用

在分镜 `visual` 中记录所选配方、作用对象、触发口播、变化前后和停留安排。一个讲解动作突出一个主要焦点；相关对象可以协同变化，但避免多个互不相关的运动争夺注意力。保留需要阅读与比较的静止区间，不按固定秒数强制换镜头。

| 配方 ID | 用途与实现方向 | 使用边界 |
| --- | --- | --- |
| `enter` | 新对象用小幅位移和缩放进入；使用 Remotion `spring` 平滑归位，透明度单独限制在 0–1 | 已经存在的对象继续保留；不重复进场，不让代码和正文持续弹跳 |
| `stagger` | 多层结构或步骤以 `enter` 错峰建立 | 错峰只表达呈现顺序，不能把并发机制画成串行执行；按讲解分组，不逐字拖慢阅读 |
| `path` | SVG 路径逐步绘制，数据标记按同一进度沿路径移动；在关键节点停留 | 表示方向与经过哪些节点；没有实测数据时，运动速度不代表实际延迟 |
| `focus` | 围绕关键对象平移、靠近，说明结束后回到能看见上下文的视野 | 保留可识别的参照物；字幕在镜头容器外；不为增加运动而持续缩放 |
| `emphasis` | 圈画、下划线或局部描边突出当前证据，适当减弱无关部分 | 位置和颜色仍可识别；强调结束后恢复；异常含义优先用明确状态文字表达 |
| `state-change` | 保留对象身份，改变值、标签、连接或内部状态，结果稳定后再继续 | 不同实体不要无解释地变形为同一实体；创建新对象、改变旧对象、替换引用要区分 |

这六种配方可组合，但无需每幕用齐。章节衔接可以直接延续同一场景，或按内容使用现有转场能力；没有叙事作用时不用转场特效。

## 使用参数

制作时将参数文件复制到项目 `src/motion-presets.json`，从该副本读取需要的值。Agent 将秒数按实际 `fps` 转成帧数，并把动作起点绑定到本幕配音边界。`distanceRatio` 表示相对相应画布轴尺寸的位移比例。路径进度使用缓入缓出，强调用透明度与描边变化，状态变化使用平滑插值。

这些数值是本项目的制作起点，不是研究给出的最佳时长，也不是强制的每幕时长。讲解需要更多观察时间时增加停留，动作来不及完成时重排分镜或调整口播，不加快 TTS 来迁就动画。项目覆盖值与理由记在 `brief.md`，不在单次视频中修改 Skill 默认文件。

已有真实字幕后，可用 [motion-cues.mjs](../scripts/motion-cues.mjs) 的 `resolveMotionCue(captions, options)` 将口播提示定位到本幕帧数。传入 `text`、`fps`、`leadFrames`；一句包含多步动作时用 `offsetRatio` 指定句内安排，配合 `durationFrames` 与 `holdFrames` 检查是否有足够时间。返回 `frame`、`captionStartFrame` 和 `captionEndFrame`。它不预测逐字时间，实际播放仍需检查。

提示短语缺失或重复时会报错；用更完整的短语明确定位，不回退到第 0 帧。提示可以跨字幕分段。需要独立复现时将该脚本与 `speech-text.mjs` 一起复制到项目 `scripts/`，动作计划放在项目 `src/` 中，由制作脚本读取当前字幕生成 `src/motion-cues.json`；这样动作计划及生成结果都纳入画面阶段的变更检查。音频或字幕更新后重新生成，再交给画面组件读取。

在 `useCurrentFrame()` 的帧数上计算动作；不能依赖 CSS animation、计时器、实时播放进度或未固定的随机值。单独抽取中间帧时也必须得到正确状态。镜头、数据路径和标签连接使用同一坐标系；改变对象位置时同步更新关联线。

## 旋转与路径几何

旋转图形的几何圆心、局部坐标原点和旋转中心保持一致。圆弧端点从同一圆心、半径与角度计算，不凭目测拼接 SVG 坐标；箭头使用路径 marker 或同一端点的切线方向。旋转期间需要保持中心稳定时，不叠加父层位移入场。重启等操作以对象状态变化解释，旋转符号只作辅助。

检查动作起点、途中多个角度和终点；整圈旋转至少覆盖四分之一圈处的状态，确认中心未漂移、箭头未脱离、终点未跳变。只有起止截图不能证明中间动作正确。

## 从设计配方到可复用组件

随 Skill 提供 [动效与场景模板库](motion-library.md)，新工程自动获得源码副本。上述六种配方表达动作意图，库中组件提供具体实现，两者不是同名映射。例如 `path` 可组合 DrawOn 和移动标记，`focus` 可用 Camera，`emphasis` 可用 Highlight 或 Underline。先查库并复用，再补充具体机制所需的代码；填写配方 ID 不会自动生成动画。

现有 `remotion`、SVG 和 `@remotion/transitions` 可用于实现基础动作，不自动安装外部动画库。官方与社区案例及采用边界见 [设计依据](design-sources.md)。已内置的实现以 catalog 为准；引入目录之外的第三方代码时仍需核对许可、依赖、中文可读性和固定帧渲染结果，参考链接不代表已经接入。
