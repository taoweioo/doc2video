# 技术动态图解

风格 ID：`technical-motion`。

将文档中的对象、关系和变化过程编排成连续的可视化讲解，适用于机制、数据流、生命周期、代码行为和方案比较。让观众能够跟踪“哪个对象发生了什么变化，以及为什么”。

## 素材与适用边界

以 SVG、HTML 和 CSS 绘制几何图形、连线、文字、代码及数据。默认不要求用户提供图片，也不依赖外部照片、录像、AI 绘图或插画包。

原文提供的图表和截图在有解释价值时可以使用。需要展示真实界面或执行结果时，使用可核实的截图、录屏或实际结果；缺失时注明演示限制，不能用绘制的界面伪装实测。仅有观点、缺少机制的章节可使用论据对照或关系图，不强行编造数据流。

## 视觉语言

- 使用浅色背景、深色正文和少量强调色。默认背景 `#F5F3EC`、正文 `#192D3C`、辅助文字 `#63727B`；蓝色 `#3367CD` 与青色 `#087F75` 区分对象或版本，橙色 `#CB542D` 强调当前变化。按内容分配语义，并在片中保持一致。
- 对象以稳定的名称、形状和颜色识别；颜色同时配合标签或状态文字，不单靠颜色表达差别。不要把 Docker 样片的 A/B、镜像层或容器外形套到其他主题。
- 中文使用清晰的无衬线字体，代码使用等宽字体；字体需许可允许使用，并在捕获帧前加载完成。针对 1920 × 1080，标题通常为 60–76 px，关键标签与字幕为 30–38 px。信息过密时拆开呈现，不靠不断缩小字号容纳。
- 画面围绕当前讲解对象布局。文字保留术语、条件和结论，代码只展示相关片段；为字幕留出独立空间。不要将整段口播做成信息卡。

## 开场与辅助信息

从第 0 帧给出完整、可识别的主题或核心问题，停留足够读清，再进入机制演示。可以让标题画面中的对象延续到首幕，不强制另加独立封面页或固定秒数。首帧不能只剩尚未连通的关系图、孤立比较符号或缺失标题；它也应适合作为视频预览画面。

常驻文字只保留对当前观看有用的信息。章名可在章节开始短暂显示，避免片名、章名、场景标题和页码重复竞争。制作说明、分镜编号放在交付资料；有误认实测风险的图形在相关位置标注“示意”，无需整片重复脚注。

## 分镜与运动

在每幕 `visual` 中描述：对象及初始状态 → 触发事件 → 动作与关系变化 → 最终状态 → 对应的口播同步点。连续讲解时沿用上幕对象，避免每讲一句就换一页。

| 要解释的内容 | 动作设计 |
| --- | --- |
| 请求与数据流 | 沿实际方向移动请求或数据标记，表现分支、折返与返回结果 |
| 引用与归属 | 标签移动时同步改变连接目标；未受影响的对象保持原状态 |
| 创建与销毁 | 在原因或输入出现之后组装新对象，明确生命周期变化 |
| 状态变化 | 保留同一对象，更新值或状态文字，突出发生变化的部分 |
| 代码执行 | 当前代码与图中的对象、变量或结果同步变化 |
| 方案对比 | 在相同输入下并列演示行为差异，再展示收益和限制 |

移动、缩放和强调都应指向当前解释重点。镜头移动用于展示局部与整体的关系，避免无目的漂移、持续弹跳和装饰性粒子。阅读代码、比较结果或理解结论时允许停留。

用实际配音的句级边界定位动作，在一句内部按语义安排先后；这些内部偏移是制作安排，不声称是逐字对齐。动作必须在对应讲解区间内完成，并给关键结果留出观察时间。正常语速下过于拥挤时，调整分镜或讲稿，再按共用流程重做排期。

制作时读取 [动效配方与默认参数](../motion.md)，按讲解目的选用自然入场、错峰组装、路径跟随、镜头聚焦、局部强调和状态变化。优先改善对象之间的衔接与焦点交接，再考虑装饰细节。参数可按本片调整，不自动启用全部配方。

分镜时从 [内置组件库](../motion-library.md) 选取与内容相配的文字、代码、路径、对照和转场。可用短暂的遮罩揭示、局部高亮、轻微背景变化增加节奏，但主体仍需演示机制。不要全片反复使用同一种淡入，也不要把每个讲解步骤装进一张独立卡片；模板中的对象应承接到下一步。

镜头默认保持稳定：建立关系时展示整体，细节影响理解时靠近，比较结果时回到能同时看见相关对象的视野。字幕与必要的解释文字保持在安全区；放大不能裁掉判断所需的参照物。章节之间可延续对象，不要求清空画面后重新搭建。

## 检查标准

- 关键机制能从对象与关系变化中看出，画面提供了口播之外的解释价值。
- 同一对象跨步骤可追踪，新增、移动、停止和保持不变不会混淆。
- 每个主要动作都有具体讲解目的；内容不会只剩标题、卡片和淡入淡出。
- 讲到相关对象时画面及时响应，状态对比和代码阅读有足够停留时间。
- 连线方向明确；图示、代码和字幕没有互相遮挡，缩小预览仍能识别重点。
- 示意和实测结果区分清楚，没有因简化画面而改变技术前提。

以上是本风格的附加检查，仍需完成共用的 [成片检查](../review.md)。
